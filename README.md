Проект является моделированием рабочего процесса data команды от загрузки сырых данных до построения витрин, аналитики и ML прогнозирования

В проекте анализируются 3 бренда авто:
- BMW
- Hyundai
- Lada

Данные загружены с Kaggle, далее создано облачное хранилище на базе Supabase (PostgreSQL), реализована 3-уровневая структура DWH как основа для feature engineering и прогнозирования продаж

Бизнес-контекст: автомобильные бренды нуждаются в прогнозировании продаж для оптимизации закупок, планирования производства и управления складскими запасами. Ошибки в прогнозе приводят к избыточным запасам или дефициту товара. В рамках проекта разработана модель прогнозирования продаж по брендам на основе исторических данных. Данные предварительно загружаются в облачное хранилище, где структурируются и готовятся к использованию в моделях

Цель проекта:
- Сравнить рыночные показатели брендов авто
- Построить метрики для анализа динамики продаж внутри бренда и между брендами
- Реализовать структуру DWH (raw-staging-core)
- Создать ML модели для прогнозирования будущих продаж
- Смоделировать production-подход к аналитике данных

Архитектура проекта:
- RAW
    - прямая загрузка сырых данных из локального окружения.
- STAGING
     - очистка, нормализация данных
     - группировка данных для достижения однородной структуры.
     - подготовка данных для расчёта
- CORE
    - расчёт брендовых KPI
    - расчёт внутренних и внешних метрик брендов
    - сравнение метрик брендов с общерыночными
    - временные агрегаты. Визуализация аналитики
    - построение прогнозных моделей

Структура ML части: 
- Тип задачи: прогнозирование временного ряда Целевая переменная: месячные продажи бренда 
- Горизонт прогноза: 1 год вперёд 
- Гранулярность: месяц х бренд 
- Стратегия разделения данных: time aware split 
- Feature engineering: временные признаки (год, месяц), лаговые признаки (скользящие средние, лаг 1-3-6), рыночные признаки (доля бренда в рынке, относительное изменение) 
- Обученные модели: LinearRegression, RandomForest, CatBoost Regressor, ElasticNet 
- Метрики оценки: MAE, RMSE, MAPE 
- Интерпретация результатов: линейная модель дала результаты лучшие, чем у сложно ансамблированных моделей. Принято решение перейти к регуляризованной линейной модели для достижения лучшей точности. Логарифмирование уменьшило дисперсию, стабилизировало прогноз. 
- Выводы: продажи по брендам показывают линейную зависимость, обладают выраженным трендом и автокорреляцией. Регуляризация повышает точность прогноза. Низкая эффективность ансамблевых методов подтверждают линейность данных
- Проверка на переобученность: Проведён анализ качества модели на обучающей и тестовой выборках. Значимого расхождения метрик не выявлено (MAE_train = 1.54, MAE_test = 1.52), что указывает на отсутствие выраженного переобучения и хорошую обобщающую способность модели.
